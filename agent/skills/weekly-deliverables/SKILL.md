# Weekly deliverables

Use this when the person wants the usual set of cuts for the night.

## Steps

1. `night_overview`: which plans exist, whether the night is indexed,
   captioned and has its music map. If something is missing, say which
   `ave` step must run first (index, caption, beats, people) and stop.
2. Decide the set: unless the person said otherwise, a 15 s and a 30 s
   vertical (9x16) and a 30 s feed (4x5). Ask one question only if the
   lengths or aspects are genuinely unclear; decide everything else and say
   what you decided.
3. For each deliverable: `plan_draft` with a new name (`reel-15`,
   `reel-30`, `feed-30`), commit it (new plans overwrite nothing), then
   follow the beat-sync-reel skill to revise it until the check passes or
   you can say why it cannot.
4. Never redraft an existing plan unless the person named it; make a new
   name instead.
5. Report at the end, not in between: one line per deliverable with its
   link (`ave://shot/<plan>/1`), length, drop bar and check result.
